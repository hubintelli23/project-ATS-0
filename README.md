# 액팅 소울 : 0 — 3D 액션 체험판

**버전 v0.2.0** · 시즌 1 「0의 시대」 제 0막 ~ 제 2막 에필로그

감정이 없는 대행자 이든이 적의 사념을 단죄하고 계승하며 인간이 되어 가는 3D 액션 JRPG의 웹 체험판입니다.
스토리는 비주얼노벨 방식으로 진행되고, 전투는 3D 실시간 액션으로 진행됩니다.
휴대폰 세로 화면을 기준으로 만들었으며, PC 브라우저에서도 키보드로 플레이할 수 있습니다.

---

## 실행 방법

이 게임은 **웹 주소로 열어야** 합니다. `index.html`을 더블클릭해서 열면 브라우저 보안 정책 때문에 이미지와 3D 화면이 나오지 않을 수 있습니다.

### GitHub Pages로 배포

1. 저장소에 아래 [파일 구성](#파일-구성) 그대로 올립니다. (`img` 폴더 포함)
2. 저장소 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정하고 저장합니다.
3. 잠시 후 표시되는 주소(`https://<아이디>.github.io/<저장소>/`)로 접속합니다.

### 내 컴퓨터에서 확인

게임 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다.

```
python -m http.server 8000
```

## 게임 흐름

| 순서 | 내용 | 전투 |
| --- | --- | --- |
| 제 0막 | 세계의 비명 — 시너지아 선택 (센티아 / 센수스) | 없음 |
| 제 1막 | 대장간의 고동 | 카르도 대련(튜토리얼) → 푸로르 |
| 제 2막 | 통곡의 숲과 뒤틀린 잔향 | 폴른 무리 → 테로르 → 포비아 |
| 에필로그 | 젖어드는 슬픔 | 없음 |

- 프롤로그의 선택에 따라 1~2막의 대사와 초반 시너지아 스킬이 달라집니다. (A: 센티아, B: 센수스)
- 각 막의 시작과 전투 직전에 자동 저장되며, 타이틀의 **이어하기**로 이어서 할 수 있습니다. (브라우저에 저장되므로 기기·브라우저가 바뀌면 이어지지 않습니다.)
- 전투에서 쓰러지면 그 전투를 처음부터 다시 합니다.

## 수정 가이드

### 대본 고치기 — `index.html`의 `SCRIPT`

대본은 `const SCRIPT=[ ... ]` 안에 순서대로 적혀 있습니다.

| 명령 | 뜻 | 예 |
| --- | --- | --- |
| `N('...')` | 서술 | `N('하늘이 찢어졌다.')` |
| `S('이름','...')` | 대사 | `S('카르도','“검을 쥐어라.”')` |
| `A(...)` / `B(...)` | 선택 A(센티아) / B(센수스)일 때만 실행 | `A(S('센티아','“...”'))` |
| `card('막','제목')` | 막 제목 화면 | `card('제 1막','대장간의 고동')` |
| `bg('이름')` | 배경 바꾸기 | rift, ruin, forge, wall, forest, village, shrine, void, black |
| `show('인물','위치')` / `hide('인물')` | 인물 등장 / 퇴장 | 위치: l, c, r |
| `fx('효과')` | 연출 | shake, flash, void, beat |
| `sys('...')` | 시스템 알림 | `sys('새 기술 「공명 베기」')` |
| `battle('보스')` | 전투 시작 | kardo, furor, fallen, teror, phobia |
| `{save:1}` | 이어하기 저장 지점 | |

대사 안에서 줄을 바꾸려면 `\n`을 씁니다.

### 전투 수치 고치기 — `action.js`

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 보스 체력, 이동 속도, 공격 간격 | `const DEFS` 안의 각 보스 (`hp`, `speed`, `gap`) |
| 보스 공격의 피해, 예고 시간, 범위 | 각 보스의 `atks` (`dmg`, `wind`, `range`·`r`·`len`) |
| 흘려보내기 가능 여부 | 공격의 `parry:1` (있으면 주황, 없으면 빨강) |
| 이든의 베기 피해와 속도 | `const SYN` (시너지아), `const TER` (테로르) |
| 경기장 크기 | `const ARENA` |
| 경기장 색과 소품 | `const STAGES` |

### 버전 표기

버전을 올릴 때는 `index.html` 타이틀 화면의 `class="ver"` 줄과 이 문서 맨 위의 버전을 같이 바꿉니다.

## 알려진 한계

- 인물은 일러스트를 세워 둔 형태이며, 공격·피격 동작 그림이 없습니다.
- 효과음은 간단한 합성음이며, 배경음악이 없습니다.
- 전투 수치는 자동 플레이로 맞춘 임시값입니다. 사람이 직접 해보고 다시 조정해야 합니다.
- 실제 휴대폰에서의 조작감과 성능은 아직 확인하지 않았습니다.
