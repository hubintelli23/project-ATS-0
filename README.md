# 액팅 소울 : 0 — 3D 액션 체험판

**버전 v0.8.0** · 시즌 1 「0의 시대」 제 0막 ~ 제 2막 에필로그

감정이 없는 대행자 이든이 적의 사념을 단죄하고 계승하며 인간이 되어 가는 3D 액션 JRPG의 웹 체험판입니다.
스토리는 비주얼노벨 방식으로 진행되고, 전투는 3D 모델로 만든 캐릭터·무기·배경 위에서 실시간 액션으로 진행됩니다.
컴퓨터(키보드·마우스)와 휴대폰(터치)을 자동으로 구분해 화면 배치와 조작이 바뀝니다. 시점은 명조처럼 마우스·드래그로 돌리는 3인칭 백뷰입니다.

---

## 실행 방법

이 게임은 **웹 주소로 열어야** 합니다. `index.html`을 더블클릭해서 열면 브라우저 보안 정책 때문에 이미지와 3D 화면이 나오지 않을 수 있습니다.

### GitHub Pages로 배포

1. 저장소에 아래 [파일 구성](#파일-구성) 그대로 올립니다. (`img` 폴더 포함)
2. 저장소 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정하고 저장합니다.
3. 잠시 후 표시되는 주소(`https://<아이디>.github.io/<저장소>/`)로 접속합니다.

### 내 컴퓨터에서 확인

게임 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다.

```
python -m http.server 8000
```

## 파일 구성

```
index.html          타이틀, 비주얼노벨 엔진, 대본(SCRIPT), 화면 디자인, 전투 HUD, 설정·지도·마스터 모드
js/engine.js        3D 엔진 (툰 셰이딩·외곽선, 기본 도형, 행렬, 카메라)
js/avatars.js       아바타 캐릭터 — 3D 몸체, 관절, 동작
js/weapons.js       무기 아티팩트 — 시너지아(센티아·센수스), 에고웨폰 테로르, 적 무기
js/effects.js       이펙트 — 베기 궤적, 불꽃, 충격파, 단죄 빛기둥, 바닥 공격 예고, 그림자
js/stages.js        배경 — 대장간·성벽·숲·사당 경기장, 먼 배경, 조명, 안개, 입자
js/assets.js        이미지 목록 — 자료실과 스토리·전투 연출이 쓰는 이미지의 이름·분류
js/action.js        전투 규칙 — 입력, 카메라, 보스 패턴, 판정, 튜토리얼, 아이템, 지도, HUD
img/                비주얼노벨용 인물 일러스트, 로고, 아이콘 (webp)
img/chars/          인물 전신 이미지 55점
img/weapons/        무기 아티팩트 이미지 23점
img/emblems/        감정 문장 · 결정, 흡융 12점
img/logos/          파레스 · 무기 문장 7점
img/unitas/         감정의 우니타스 5팀 인물 15점 (교만·분노·두려움·슬픔·기쁨, 팀당 3명)
updates.json        업데이트 기록 (최신이 맨 위) — 타이틀의 「업데이트 기록」 버튼이 읽어서 보여줌
README.md           이 문서
```

스크립트는 `engine → effects → weapons → avatars → stages → assets → action` 순서로 불러옵니다. 순서를 바꾸면 동작하지 않습니다.

js 파일은 `js` 폴더에서 먼저 찾고, 없으면 index.html 과 같은 폴더에서 다시 찾습니다.

**중요: 위 파일은 항상 함께 올려야 합니다.** 일부만 바꿔 올리면 스토리는 진행돼도 전투가 시작되지 않습니다. 이 경우 타이틀 화면에 빨간 안내로 어떤 파일이 없거나 버전이 다른지 표시됩니다. 업데이트할 때는 zip 을 풀어 **전부** 덮어쓰고, 휴대폰은 캐시를 지운 뒤 다시 열어 주세요.

외부 라이브러리는 쓰지 않습니다(3D 엔진도 직접 작성). 글꼴(나눔명조, 고운돋움)만 Google Fonts에서 불러오며, 불러오지 못하면 기기 기본 글꼴로 표시됩니다.

## 네시스 · 흡융 즉사 기믹 (시험 전투)

마스터 모드 → 전투 바로 가기 → **네시스 · 흡융 기믹 (시험)** 에서 해볼 수 있습니다. 스토리에는 아직 들어가지 않습니다.

네시스는 「흡융」으로 즉사 기믹을 전개합니다. **피하는 것이 아니라, 기믹이 완성되기 전에 흡융 현상을 제거해야** 합니다.

| 단계 | 내용 (시험값) |
| --- | --- |
| 생성 | 네시스 체력 70%·40%에서 경기장 가운데로 물러나 흡융 전개. 이때 네시스는 피해를 받지 않음. 가장자리 쪽에 **흡융 핵 3개** 생성, 이든을 가운데로 끌어당김(시간이 갈수록 강해짐). 흡융탄(빨간 원)으로 방해 |
| 제거 수단 | ① 핵을 공격으로 부숨 (핵 체력 30 — 일반 공격 3~4번, 강공격 2번) ② 핵 5m 안에서 **공허의 시야(Q)** — 범위 안의 핵을 한 번에 지움 ③ **궁극기(R)** — 7.5m 안의 핵을 지움 |
| 제한 시간 | 1회차 14초, 2회차 11초. 화면 가운데 카운트다운, 미니맵에 핵 위치(주황 점) |
| 성공 | **흡융 역류** — 네시스 6초 무방비, 받는 피해 1.5배, 공명 +25 |
| 실패 | 핵이 하나라도 남으면 **즉사** (마스터 모드 무적이면 버팀) |

수치는 `js/action.js` 맨 위쪽의 `FUSE` 한 줄에서 바꿉니다 (발동 체력, 제한 시간, 핵 개수·체력, 공허·궁극기 범위, 끌어당김 세기, 무방비 시간, 피해 배율).

## 진동

피격, 큰 화면 흔들림, 즉사, 흡융 카운트다운 마지막 3초, 스토리 연출(흔들림·섬광·심장박동)에 맞춰 휴대폰이 진동합니다. 설정(Esc)의 **진동**에서 켜고 끕니다.
안드로이드 휴대폰(크롬 등)에서 동작합니다. 아이폰은 브라우저(사파리)가 웹 진동을 막고 있어 울리지 않습니다.

## 자료실

타이틀 화면의 **자료실**에서 게임에 들어 있는 이미지를 분류별(인물 · 감정의 우니타스 · 무기 · 감정 문장·결정 · 문장)로 볼 수 있습니다. 누르면 크게 보이고, 제 0막~2막에 나오는 것에는 「체험판 등장」이 붙습니다.

**새 이미지 넣는 법**
1. 이미지를 webp 로 바꿔 `img/<분류>/<영문이름>.webp` 로 저장합니다. (분류: `chars` · `unitas` · `weapons` · `emblems` · `logos`)
   우니타스 팀원은 `team:'anger'` 처럼 팀을 적으면 자료실에서 팀별로 묶입니다. 팀 이름은 `teams` 에서 바꿉니다.
2. `js/assets.js` 의 같은 분류 목록에 `{id:'영문이름',name:'표시할 이름'}` 한 줄을 추가합니다. 체험판에 나오면 `demo:1` 을 붙입니다.
3. 파일 이름은 영문으로 씁니다. 한글 파일 이름은 GitHub Pages 주소에서 깨질 수 있습니다.

체험판 연출에 쓰는 곳
- 전투 시작 카드: 보스 초상 · 무기 · 감정 문장 — `js/action.js` 의 `CARD`
- 스토리 연출 이미지: 대본(SCRIPT)의 `{art:['분류/이름', …], cap:'글자'}` 명령 — 시너지아 합일, 테로르 사념 포획, 두려움의 성흔 흡수
- 시너지아 선택지 아이콘: `img/logos/sentia.webp`, `img/logos/sensus.webp`

**공격 예고 색**: 바닥에 **주황색** 범위가 뜨면 맞춰서 회피해 흘려보낼 수 있고, **빨간색** 범위는 피해야 합니다. 원형·직선 범위는 점프로 뛰어넘을 수도 있습니다.

**스토리 스킵**: 스토리 화면 위쪽의 「스킵」을 누르면(PC는 S키) 「스킵 중」으로 바뀌고, 다음 선택지나 전투가 나올 때까지 대사와 연출을 한 번에 넘깁니다. 선택지·전투에 닿으면 저절로 꺼지고, 도중에 다시 누르면 멈춥니다. 넘긴 대사는 「기록」에서 다시 볼 수 있습니다.

조작 방식은 자동으로 정해지며, 설정(Esc)의 「조작 방식」에서 컴퓨터/휴대폰으로 고정할 수 있습니다.

## 수정 가이드

### 대본 고치기 — `index.html`의 `SCRIPT`

대본은 `const SCRIPT=[ ... ]` 안에 순서대로 적혀 있습니다.

| 명령 | 뜻 | 예 |
| --- | --- | --- |
| `N('...')` | 서술 | `N('하늘이 찢어졌다.')` |
| `S('이름','...')` | 대사 | `S('카르도','“검을 쥐어라.”')` |
| `A(...)` / `B(...)` | 선택 A(센티아) / B(센수스)일 때만 실행 | `A(S('센티아','“...”'))` |
| `card('막','제목')` | 막 제목 화면 | `card('제 1막','대장간의 고동')` |
| `bg('이름')` | 배경 바꾸기 | rift, ruin, forge, wall, forest, village, shrine, void, black |
| `show('인물','위치')` / `hide('인물')` | 인물 등장 / 퇴장 | 위치: l, c, r |
| `fx('효과')` | 연출 | shake, flash, void, beat |
| `sys('...')` | 시스템 알림 | `sys('새 기술 「공명 베기」')` |
| `battle('보스')` | 전투 시작 | kardo, furor, fallen, teror, phobia |
| `{save:1}` | 이어하기 저장 지점 | |

대사 안에서 줄을 바꾸려면 `\n`을 씁니다.

### 에셋 교체 가이드 (캐릭터 · 무기 · 이펙트 · 배경)

네 가지 에셋은 각자 파일이 나뉘어 있어서, 해당 파일만 바꾸면 다른 파일은 손대지 않아도 됩니다.
각 파일 맨 위 주석에 같은 설명이 있습니다.

| 에셋 | 파일 | 바꾸는 곳 | 연결되는 곳 |
| --- | --- | --- | --- |
| 아바타 캐릭터 | `avatars.js` | `AVATARS` 의 각 항목 (색, 머리 모양, 옷, 후드, 키, 추가 부품) | `action.js` 보스 정의의 `tex` 이름 |
| 무기 아티팩트 | `weapons.js` | `WEAPONS` 의 각 항목 (부품 모양·색·발광, 궤적 색) | `avatars.js` 의 `weaponR` / `weaponL` |
| 이펙트 | `effects.js` | `makeTextures` (모양), `FX.spawn` (크기·수명·움직임) | `action.js` 의 `FX.spawn(...)` 호출 |
| 배경 | `stages.js` | `STAGES` 의 각 항목 (바닥·안개·빛 색, 소품, 먼 배경, 입자) | `action.js` 보스 정의의 `stage` 이름 |

- **새 캐릭터 추가**: `AVATARS` 에 항목을 하나 만들고, 보스 정의의 `tex` 에 그 이름을 적습니다.
- **새 무기 추가**: `WEAPONS` 에 항목을 만들고 캐릭터의 `weaponR` 에 적습니다. 손잡이가 원점, 칼날은 `-y` 방향으로 만듭니다.
- **이든의 무기**: 상황(파트너 선택, 합일, 테로르 장착)에 따라 `action.js` 의 `edenWeapons()` 가 바꿉니다.
- **나중에 실제 3D 모델 파일(glTF·VRM 등)로 바꿀 때**: `Avatars.create()` 가 돌려주는 객체의 `play(동작, 진행도)` · `update(dt)` · `draw(x, y, z, 방향, 옵션)` 세 함수만 같은 이름으로 구현하면 전투 코드는 그대로 동작합니다. 무기는 `Weapons.draw(이름, 손 행렬)`, 배경은 `Stages.drawSolid()` 가 같은 역할입니다.

### 전투 수치 고치기 — `action.js`

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 보스 체력, 이동 속도, 공격 간격 | `const DEFS` 안의 각 보스 (`hp`, `speed`, `gap`) |
| 보스 공격의 피해, 예고 시간, 범위 | 각 보스의 `atks` (`dmg`, `wind`, `range`·`r`·`len`) |
| 흘려보내기 가능 여부 | 공격의 `parry:1` (있으면 주황, 없으면 빨강) |
| 이든의 베기 피해와 속도 | `const SYN` (시너지아), `const TER` (테로르) |
| 경기장 크기 | `stages.js` 의 `ARENA` |
| 카메라 거리·높이 | `action.js` 맨 위 `CAM` 의 `dist`, `pitch` |
| 강공격 홀딩 기준 | `action.js` 맨 위 `HOLD` (0.5초) |

### 버전 표기

버전을 올릴 때는 아래를 같이 바꿉니다.

- `index.html` 타이틀 화면의 `class="ver"` 줄과 맨 위 주석
- `index.html` 맨 위 스크립트의 `GAME_VERSION`
- 각 `.js` 파일 맨 위의 `AS_VERSIONS[...]='버전'` 한 줄 (index.html 의 `GAME_VERSION` 과 같아야 함)
- 각 `.js` 파일 맨 위 주석의 버전
- 이 문서 맨 위의 버전
- **updates.json** 맨 앞에 새 버전 항목 추가 (`current` 도 바꿈)

## 알려진 한계

- 3D 캐릭터와 무기는 기본 도형(상자·구·원기둥)을 조립한 임시 모델입니다. 실제 모델로 교체할 자리를 위 가이드처럼 비워 두었습니다.
- 비주얼노벨(스토리) 화면은 2D 일러스트를 그대로 씁니다.
- 효과음은 간단한 합성음이며, 배경음악이 없습니다.
- 전투 수치는 자동 플레이로 맞춘 임시값입니다. 사람이 직접 해보고 다시 조정해야 합니다.
- 실제 휴대폰과 실제 마우스로의 조작감·성능은 아직 확인하지 않았습니다(자동 플레이로만 확인).
- 일부 브라우저나 미리보기 화면에서는 마우스 고정(포인터 잠금)이 막힐 수 있습니다. 그때도 마우스를 움직이면 시점이 돌아갑니다.
